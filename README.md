# WebForge IDE

Полноценная локальная среда для HTML, CSS и JavaScript.

## Возможности

- Редактор кода на CodeMirror 6
- Подсветка HTML, CSS, JavaScript
- Живой предпросмотр
- Консоль предпросмотра
- Перехват `console.log`, `console.warn`, `console.error`
- Экспорт готового HTML
- Сохранение проекта в JSON
- Автосохранение локальной сессии
- Тёмная и светлая тема
- Плавные анимации интерфейса
- Сборка Windows `.exe` через GitHub Actions
- Автоматическая генерация иконки при сборке

## Локальный запуск

```bash
npm install
npm run dev
